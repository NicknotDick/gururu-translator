# Gururu 翻译

Windows 单文件绿色版翻译工具。默认打开即为「中文 → 英语」文本翻译，另支持八种办公文档的**保版翻译**，输出文件自动加 `_译文` 后缀。

最小化后驻留系统托盘，关闭窗口即退出程序。

- 免安装、零依赖、不写注册表，配置全部保存在程序同级 `data/`
- 内置免 Key 公共翻译引擎，装好即可用
- 可接入 DeepSeek / OpenAI / 通义 / 智谱 / Kimi 或任意 OpenAI 兼容端点，启用翻译风格与行业术语强制锁定
- 支持仅译文与双语对照两种输出，翻译后可在预览界面逐段修改，并可用 AI 按指令实时调整译文

**作者**：Gururu Nick　**版本**：Gurutu + 打包时刻（YYMMDDHHMM），如 `Gurutu2610291849`

## 快速开始

1. 双击 `Gururu 翻译.exe`
2. 顶部选择语言（默认 中文 ⇄ 英语），在左侧输入框粘贴文本，按 `Ctrl+Enter` 或点「翻译」
3. 需要文档翻译时切到「文档翻译」，添加文件 → 选模式 → 开始翻译

首次运行会在程序同级生成：

```
data/settings.json   配置（API Key 经 Windows DPAPI 加密）
data/tm.db           翻译记忆缓存
data/logs/app.log    运行日志
output/              默认译文输出目录
```

整个文件夹可拷贝到 U 盘使用。

## 支持的格式

| 格式 | 扩展名 | 保版方式 | 双语对照 |
|---|---|---|---|
| Word | `.docx` | 段落级替换，样式/编号/表格/页眉页脚保留 | 原文段后插入译文段 |
| Excel | `.xlsx` `.xlsm` | 单元格级替换，公式与合并区不受影响 | 右侧插入译文列，公式引用自动平移 |
| PowerPoint | `.pptx` | 形状/表格/组合内文字替换，自动缩字号防溢出 | 原段落下方插入译文段 |
| PDF | `.pdf` | 按文字块坐标擦除原文后原位回填，页数/图片/表格线不变 | 同一文字块上下各占一半 |
| Visio | `.vsdx` | 直接改写页面 XML 的文本节点，图形位置完全不动 | 不支持（按仅译文输出） |
| Markdown | `.md` `.markdown` | 保护 front-matter、代码块、链接、URL | 原文行下插入 `>` 引用块 |
| 纯文本 | `.txt` | 合并软换行后按段落翻译 | 原文段后插入译文段 |
| EPUB | `.epub` | 按 spine 顺序改写 XHTML 文本节点 | 段落下方插入译文段 |

不支持旧版二进制格式（`.doc` / `.xls` / `.ppt` / `.vsd`），程序会提示先另存为新格式。

扫描件 PDF（无文字层）当前版本不支持，程序会明确提示；OCR 属 v2 扩展能力。

## 翻译引擎

**公共引擎（默认）** 使用腾讯 TranSmart 免 Key 接口，失败时自动降级到 MyMemory，全部失败则原文返回并标记失败段，不会卡死。公共引擎不支持风格与术语。

**大语言模型** 在「设置 → 大语言模型」中填写接口地址、模型与 API Key：

| 服务商 | 接口地址 | 常用模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-air` |
| 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 自建 | 任意 OpenAI 兼容端点 | 自定义 |

填好后点「测试连接」验证，再把「默认引擎」切换为大语言模型。只有大模型模式会应用翻译风格与术语锁定。

## 风格与术语

- 内置 6 种风格：标准通用、正式公文、学术论文、技术文档、商务沟通、口语自然
- 内置 6 个术语库：IT/软件、医疗/生物、法律/合同、机械/制造、金融/财务、**SAP 企业应用（115 条，覆盖 FI/CO/MM/SD/PP 与实施通用词）**
- 默认启用「IT / 软件」与「SAP 企业应用」两套，可在下拉框里自由增减
- 「设置 → 术语库」可新建自定义库、逐条添加，或从 CSV/Excel 批量导入（列序：源词、译词、源语言、目标语言），模板见 `resources/glossary_import/`
- 术语命中后强制锁定译法：翻译时先替换为占位符，译后回填并校验，未通过则标橙待人工确认

## 查词

「查词」位于左侧导航**第一项**，是当前主推功能；可在 设置 → 常规 → 启动页 中把它设为默认打开页。

- **离线**：内置约 3 万高频词英汉词典（源自开源 ECDICT，裁剪后约 3.9 MB，SQLite 打包在程序内），显示音标、词性、多义项、Collins/Oxford 等级与词形变化；支持词形还原（studies → study）
- **输入联想**：输入 2 个字符即弹出候选，先出本地结果（精确 → 前缀 → 包含 → 编辑距离纠错），再补充有道在线联想（含拼写纠正，如 recieve → receive 置顶）；支持 ↑/↓ 选择、Enter 确认、Esc 关闭
- **在线词典**：并行请求有道词典与 Free Dictionary，返回后追加为独立卡片；任一源失败不影响其它源
- **百科图文**：有道接口自带维基摘要与配图，查词时自动追加「百科」卡片——图片经程序代理下载后内嵌显示，英文摘要自动补一段中文翻译
- 断网时仅显示内置词条，不报错

## 桌面快捷方式

设置 → 缓存与运行 → **创建桌面快捷方式**：在当前用户桌面生成指向本程序的 `Gururu 翻译.lnk`（含图标），适用于绿色版拷到任意目录后固定入口。重复点击会覆盖更新。

## 重复启动检测

已有实例在运行时，会弹出三选对话框：

| 选项 | 行为 |
|---|---|
| 是 | 把正在运行的窗口切到前台，退出本次启动 |
| 否 | 先请求关闭旧实例（4 秒未退则强制结束），再启动新实例 |
| 取消 | 不启动 |

对话框文案随界面语言切换。

## 界面布局

设置页固定两列卡片：同行等高、列宽一致，窗口变窄时自动降为单列；「保存设置」按钮固定在底部，滚动时始终可见。

## 输出目录

文档翻译页与设置页的「输出目录」都是两个按钮：

- 左侧显示当前目录（过长时自动省略），**点击直接在资源管理器中打开该文件夹**
- 右侧「…」按钮用于**更换**输出目录

## 界面语言与语言名称

设置 → 常规 → 界面语言，可选 **中文 / English**：

- 切换立即生效并自动保存，重启保持
- 英文模式下全部界面文案（导航、设置项、对话框、状态与提示）均为英文，工程提示与后端错误同步切换
- 语言选择器始终用**各自语言的本名**显示：English / 中文 / 日本語 / Deutsch / Español …，因此在英文界面下翻译方向会呈现为 `English → 中文`

## 界面色调

设置 → 界面 → 色调，三档可选：

- **跟随系统**（默认）：读取 Windows「应用模式」，系统在浅色/深色间切换时界面同步变化
- **浅色** / **深色**：固定使用该色调

切换立即生效并自动写入配置，下次启动保持一致。启动阶段已把主题预注入页面，不会出现先亮后暗的闪屏。两套主题共用同一套语义色令牌，所有页面（文本、文档、预览、关于、弹窗）均同步适配。

## 预览调整

文档翻译完成后，队列行点「✎」进入预览：

- 左栏原文（只读），右栏译文可直接编辑，改动即时回写内存
- 切换风格或术语库会重译全部段落，**已手动修改的段落会保留**
- 顶部可切换「仅目标语言 / 双语对照」，点「保存输出」按新设置重写文件

### AI 实时调整

预览页**底部**固定一条 AI 指令栏，用于在译后按自然语言要求改写译文（**需先配置大模型 API Key**）：

1. 点击左侧原文可选中段落（再点一次取消），不选则作用于全部
2. 在输入框写明要求，例如「更正式一些」「压缩到原句一半长度」「统一把“接口”改称 API」
3. 点「AI 调整」或按回车，只把受影响段落送模型，返回后原地刷新，无需重新翻译整篇

被 AI 改写的段落状态点变为紫色，统计行显示「AI 润色 N」；手动编辑过的段落仍可被 AI 调整覆盖，但「全部重译」不会覆盖手动编辑的段落。

## 从源码运行与打包

```bash
python -m pip install -r requirements.txt
python -m app.main                 # 开发模式直接运行

python tools/make_samples.py       # 生成八种格式测试样例
python tools/smoke_test.py         # 逐格式解析→翻译→写回自检
python tools/test_batch.py         # 队列级批量测试
python tools/test_llm.py           # 大模型通道离线测试（本地 mock）

python tools/test_refine.py        # AI 调整链路离线测试（本地 mock）
python tools/build_dict.py         # 由 ECDICT 生成内置词典 resources/dict.sqlite3

python tools/build.py              # 一键构建：刷版本号 → 生成图标 → 内联前端 → 打包
```

`tools/build.py` 等价于依次执行：

```bash
python tools/stamp_version.py      # 版本号 = Gurutu + 当前 YYMMDDHHMM
python tools/make_assets.py        # 生成图标与启动图
python tools/embed_ui.py           # 前端内联为 app/ui_bundle.py
python -m PyInstaller build/app.spec --noconfirm --clean
```

产物为 `dist/Gururu 翻译.exe`（单文件、约 63 MB）。

## 已知限制

- **PDF 许可证**：使用 PyMuPDF，自用无影响；对外商业分发需遵循 AGPL 或购买 Artifex 商业许可
- **PDF 溢出**：译文比原文长时自动缩小字号，极端情况仍可能溢出，预览中以黄点标出
- **Excel 图片**：openpyxl 重新保存会丢失内嵌图片，程序在解析时给出警告
- **Visio 富文本**：同一形状内多段不同格式的文本会被合并为一段
- **公共引擎**：免 Key 接口可能随时失效，接口地址与 client_key 已配置化，可在 `settings.json` 内热更新
- **Markdown 链接**：为保证 URL 不被破坏，`[文字](链接)` 整段保持原文不译

## 存放位置说明

程序可放在任意可写目录（桌面、D 盘根目录、U 盘等）。**不建议放在 `Program Files`、`C:/Program Files (x86)` 等系统受保护目录**——这类目录普通权限无法写入。

若检测到程序目录不可写，程序会自动把 `data/` 与 `output/` 转存到：

```
%LOCALAPPDATA%\Gururu 翻译\
```

设置 → 缓存与运行 中显示的即为实际数据目录，可点击直接打开。
